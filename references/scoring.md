# Scoring (GooglePlayGrowth heuristic)

The score is a **GooglePlayGrowth heuristic**. It is NOT an official Google Play rating and NOT a ranking or installs prediction. Always say so beside the score.

## Dimensions (0–100 each)
| Dimension | Looks at |
|---|---|
| Relevância dos metadados | title/short/long reflect what the app is and what users search |
| Clareza da proposta de valor | who it is for and why, within seconds |
| Cobertura semântica | primary, secondary, long-tail coverage without stuffing |
| Qualidade da comunicação | readability, structure, specificity, tone |
| Diferenciação | distinct from verified competitors |
| Apresentação visual | icon, screenshots, order, text on images |
| Coerência | consistency of promise across title, descriptions, visuals, reputation |

## Rules
- Score only what was observed. A dimension without data (e.g., no screenshots seen) is **não avaliada** and excluded from the average; say how many of 7 dimensions were evaluated.
- Overall = simple average of evaluated dimensions, then apply caps.
- **Caps for critical problems** (overall cannot exceed): policy violation in title/icon/short description → 60; misleading or false claim → 50; limit exceeded in live listing → 70; core function not identifiable from title+short description → 65; recurring review-reported breakage that contradicts the promise → 75. List the capping problem next to the score.
- Give a one-line justification per dimension citing evidence labels.
- Never present a high score without listing open critical issues.
- Show bands: 0–39 crítico, 40–59 fraco, 60–74 regular, 75–89 bom, 90–100 excelente.
