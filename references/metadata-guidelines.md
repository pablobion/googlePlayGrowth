# Metadata writing guidelines

Limits and prohibitions: see `google-play-policies.md` (mandatory check). This file covers craft.

## Title (30)
- Brand + primary keyword when brand alone is not searchable ("Brand: Keyword Phrase"). Brand-only titles waste the strongest ranking field unless the brand is already the main search term.
- One primary keyword, optionally one close modifier. Natural reading; no keyword lists.
- No emoji, promo words, ranking claims, ALL CAPS.
- Offer 3 options with different angles (brand-led, keyword-led, benefit-led).

## Short description (80)
- Lead with the main benefit for a specific user, include 1–2 priority keywords naturally.
- Plain text only. No banned CTAs ("download now" etc.), no symbols/emoji.
- 3 alternatives with different angles (benefit, use case, differentiator).

## Full description (4,000)
- First ~2–3 lines carry the value proposition and primary keyword (visible before "read more").
- Adapt structure to the app type; typical blocks: value proposition, benefits, key features, differentiators, use cases, trust/credibility (attributed only), soft closing. Use short paragraphs and simple bullets. Drop blocks that do not apply.
- Primary keyword: natural repetition (a few times across the text, never forced); secondary and related terms spread where they fit the sentence.
- Only describe features the app has, evidenced by the page, user input or the app itself. If unsure, ask or leave out.
- Do not copy the short description; do not compare to other apps; no unattributed testimonials.

## Localization
Write for the target market, not a translation: local search phrasing, local units, tone. pt-BR and en first. Note if a term is used differently in the target market.

## Validation checklist (every deliverable)
1. Count characters (spaces, punctuation, line breaks, emoji included) for each text; show `N/limit`.
2. Re-count after any edit.
3. Over the limit = not deliverable; shorten and re-count.
4. Run the policy prohibitions list.
5. Every claim traceable to a real feature.
6. Keyword density sanity: read it aloud; if it sounds like a list, rewrite.
